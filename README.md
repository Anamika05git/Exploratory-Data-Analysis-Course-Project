
# Exploratory Data Analysis — Course Project

## Overview
This project implements nine Data Analysis (DA) lab assessments originally performed using R programming, now implemented in Python. It covers data transformation, data cleaning, statistical analysis, visualization, time series analysis, clustering, and Principal Component Analysis (PCA).

## Dataset
The primary dataset used in the dataset-based assessments is `indo_rct.csv`, provided through the course materials.

Dataset source: [indo_rct.csv](https://raw.githubusercontent.com/salemprakash/EDA/main/Data/indo_rct.csv)

The Time Series Analysis assessment uses the AirPassengers dataset, as specified in the original assessment instructions.

## Assessments Covered

1. **DA 1 — Dataframe Operations and Data Transformations:** Dataframe creation, concatenation, merging, joins, and normalization techniques.
2. **DA 2 — Data Import, Transformation and Basic Statistical Analysis:** Data exploration, missing-value handling, duplicate removal, and descriptive statistics.
3. **DA 3 — Data Cleaning and Univariate Analysis:** Data cleaning, outlier detection, frequency distributions, and univariate visualizations.
4. **DA 4 — Bivariate Analysis:** Contingency tables, correlation, scatterplots, grouped bar charts, boxplots, and heatmaps.
5. **DA 5 — Multivariate Analysis:** Multivariable scatterplots, bubble plots, faceting, pairs plots, and parallel-coordinates plots.
6. **DA 6 — Time Series Analysis:** AirPassengers time-series visualization, decomposition, autocorrelation, seasonal ARIMA modelling, and forecasting.
7. **DA 7 — 1D, 2D and ND Analysis:** Descriptive statistics, frequency distributions, grouped analysis, correlation, and multivariable visualization.
8. **DA 8 — Clustering:** K-Means clustering, the elbow method, hierarchical clustering, and dendrogram visualization.
9. **DA 9 — Principal Component Analysis:** Data standardization, PCA, explained variance, scree plot, biplot, and PCA scores visualization.

1. Open `EDA_DA_Assignments.ipynb` in Google Colab or Jupyter Notebook.
2. Execute the cells in order, beginning with the relevant imports and dataset preparation.
3. Ensure the required Python libraries are installed.
4. Review the outputs, statistical summaries, and visualizations generated by each assessment.
